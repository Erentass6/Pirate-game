# Korsan Savaşları — Pirate Adventure

A Turkish-language, turn-based browser game set on a 6×6 sea map. Sail between encounters, manage health, and decide when to attack, use a special move, or retreat.

## Gameplay

- Navigate the map with the on-screen arrows
- Resolve encounters with normal attacks, a cooldown-based special attack, or a risky escape
- Discover treasure and friendly or hostile encounters
- Regenerate health over time
- Toggle generated music and sound effects

## Run locally

Open `index.html` in a modern browser. The project uses plain HTML, CSS, and JavaScript and has no build step or backend.

## Files

- `index.html` — game interface
- `style.css` — visual design
- `game.js` — map, encounters, combat, and Web Audio effects
- `korsan_oyunu_v2.zip` — original archive

## Scope

The game runs locally in the browser. It has no online multiplayer or cloud save system.
